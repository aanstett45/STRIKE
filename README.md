This repository contains the source code, experiment scripts, raw benchmark outputs, and figure-generation utilities for the article **“Cross-row pointer persistence in merge-based sparse matrix products.”**

The intended archival release is **v1.0.0**.

## Reproducibility rules

Use the following defaults :

```bash
export OMP_SCHEDULE=static
```

On the Raspberry Pi also use:

```bash
export OMP_PROC_BIND=close
export OMP_PLACES=cores
```

The random seeds are fixed in the source code. The principal matrix seeds are `42` and `1000`; trial repetitions increment them deterministically.

Each benchmark performs one unmeasured warm-up. Standard output includes `[spread]` lines containing the minimum, median, and maximum measured times. Preserve standard output in `.log` files.

## 1. Verification

### MacBook

```bash
mkdir -p results/macbook
OMP_SCHEDULE=static ./build/finger_spgemm verify \
  2>&1 | tee results/macbook/verify.log
```

### Raspberry Pi

```bash
mkdir -p results/raspberry_pi
OMP_SCHEDULE=static \
OMP_PROC_BIND=close \
OMP_PLACES=cores \
./build/finger_spgemm verify \
  2>&1 | tee results/raspberry_pi/verify.log
```

The deterministic full-SpGEMM verification must report the following unguarded-kernel differences and survival rates:


| Configuration                         | Difference count |         Survival rate |
| ------------------------------------- | ---------------: | --------------------: |
| Random,`n=512`, `d=0.02`, `beta=0.6`  |           45,592 |   approximately 0.42% |
| Band,`n=1024`, `w=16`                 |           30,255 |  approximately 51.28% |
| Random,`n=2048`, `d=0.01`, `beta=0.6` |          704,747 | approximately 0.0703% |

The stateless, guarded, and guarded-plus-galloping kernels must match the Gustavson reference. All triangle-count cross-checks must end with `[OK]`.

## 2. Thread-count sweep

The graph set is:

```text
data/roadNet-CA.txt
data/email-Enron.txt
gen:band:20000:16
gen:ba:20000:8
```

### MacBook: 1, 2, 4, 8, and 12 threads

```bash
mkdir -p results/macbook/threads

for k in 1 2 4 8 12; do
  OMP_SCHEDULE=static \
  ./build/finger_spgemm triangles \
    "results/macbook/threads/tri_T${k}.csv" \
    --runs 5 --threads "${k}" \
    data/roadNet-CA.txt \
    data/email-Enron.txt \
    gen:band:20000:16 \
    gen:ba:20000:8 \
    2>&1 | tee "results/macbook/threads/tri_T${k}.log"
done
```


To count spread records per log:

```bash
find results -name '*.log' -print0 | while IFS= read -r -d '' f; do
  printf '%s: ' "$f"
  grep -c "\[spread\]" "$f" || true
done
```

## Validate generated files

Check that every CSV is non-empty:

```bash
find results -name '*.csv' -size 0 -print
```

The command should print nothing.

Check triangle correctness flags:

```bash
awk -F, 'NR > 1 && $NF != 1 {print FILENAME ":" NR ": " $0}' \
  results/macbook/threads/*.csv \
  results/macbook/scheduling/*.csv \
  results/raspberry_pi/threads/*.csv
```

The command should print nothing.

Check full-SpGEMM guarded-plus-galloping correctness:

```bash
awk -F, 'NR > 1 && $NF != 1 {print FILENAME ":" NR ": " $0}' \
  results/macbook/fullspgemm.csv \
  results/macbook/full_wide.csv
```

The command should print nothing.
